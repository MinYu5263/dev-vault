## @PathVariable

**说明**：接收路径中的参数。

**调用示例**：

```http
// 传递单个参数
GET http://localhost:8080/demo/path/100

// 传递多个参数
GET http://localhost:8080/demo/path/100/orders/2023001
```


**后端代码**：

```java
@RestController
@RequestMapping("/demo")
public class DemoController {
	
	// 单个路径参数
    @GetMapping("/path/{id}")
    public String getByPath(@PathVariable Long id) {
        return "接收路径参数：" + id;
    }
    
    // 多个路径参数
    @GetMapping("/path/{userId}/orders/{orderId}")
    public String getPathParams(@PathVariable Long userId, @PathVariable String orderId) {
        return "用户ID: " + userId + ", 订单ID: " + orderId;
    }
}
```

## @RequestParam

**说明**：接收查询参数或表单参数，格式为`?key=value`

**调用示例**：

```http
GET http://localhost:8080/demo/query?name=张三&age=25&size=20
```

**后端代码**：

```java
@RestController
@RequestMapping("/demo")
public class DemoController {
    @GetMapping("/query")
    public String getByQuery(
            @RequestParam String name, // 必传参数
            @RequestParam(required = false) Integer age, // 非必传参数
            @RequestParam(defaultValue = "10") Integer size // 带默认值的参数
    ) {
	    return "姓名: " + name + ", 年龄: " + age + ", 每页大小: " + size;
    }
}
```


> [!tip] 提示
> 如果参数很多，也可以使用实体类接收。但是要注意：实体类中的属性名与前端参数名需保持一致

## @RequestBody

**说明**：传递复杂对象，常见格式一般为JSON和XML，JSON一般居多。

**调用示例**：

```http
POST http://localhost:8080/demo/body
Content-Type: application/json

{
    "username": "张三",
    "email": "zhangsan@example.com"
}
```

**后端代码**：

```java
// 定义实体类
public class User {
    private String username;
    private String email;
    // 省略getter、setter、构造函数
}

// Controller
@RestController
@RequestMapping("/demo")
public class DemoController {
    @PostMapping("/body")
    public String getBody(@RequestBody User user) {
        return "接收用户信息：" + user.getUsername() + "，邮箱：" + user.getEmail();
    }
}
```

## 接收文件

**前端代码**：

```javascript
function uploadFile() {
  // 1. 获取文件和参数（和示例1一致）
  const selectedFile = document.getElementById("fileInput").files[0];
  const fileName = document.getElementById("fileNameInput").value;

  if (!selectedFile) {
    alert("请选择文件！");
    return;
  }

  // 2. 构造 FormData
  const formData = new FormData();
  formData.append("file", selectedFile); // key="file" 与后端匹配
  formData.append("name", fileName);

  // 3. Axios发送请求（无需手动处理响应解析）
  axios.post("http://localhost:8080/file/upload", formData)
    .then(response => {
      alert("发送成功！\n" + response.data); // response.data 直接是后端返回结果
    })
    .catch(error => {
      alert("发送失败：" + error.message);
    });
}
```

**后端代码（yaml）**：

```yaml
# application.yml 配置文件大小限制
spring:
  servlet:
    multipart:
      max-file-size: 10MB # 单个文件最大大小
      max-request-size: 50MB # 单次请求总文件大小
```

**后端代码（Controller）**：

```java
import org.springframework.web.bind.annotation.*;
import org.springframework.web.multipart.MultipartFile;

@RestController
@RequestMapping("/file")
public class FileUploadController {

    @PostMapping("/upload")
    public String uploadFile(
            @RequestParam("file") MultipartFile file,  // 核心：接收文件
            @RequestParam(value = "name", required = false) String fileName  // 可选文本参数
    ) {
        // 基本校验：文件是否为空
        if (file.isEmpty()) {
            return "文件不能为空";
        }

        // 核心信息：获取文件基本属性（展示如何读取文件信息）
        String originalName = file.getOriginalFilename();  // 原始文件名
        long fileSize = file.getSize();  // 文件大小（字节）
        String contentType = file.getContentType();  // 文件类型（如image/jpeg）

        // 此处省略文件保存逻辑，仅返回接收结果
        return String.format(
            "文件接收成功！\n原始文件名：%s\n文件大小：%d字节\n文件类型：%s\n附加名称：%s",
            originalName, fileSize, contentType, fileName
        );
    }
}
```


## 注意事项
### Get 请求禁止携带请求体

在技术层面上，Get是可以携带请求体的，但是几乎没人会这么做。请求体一般是向后端提交的数据，一般只有Post和Put请求会包含请求体，这已经算是行业的规范了。~~仔细想想这样非常合理，Get是要从后端获取数据，为什么还要提交数据呢？提交参数？~~

虽然技术上Get是可以携带请求体的，但是大多数后端框架在接收Get请求时会忽略请求体，例如SpringBoot框架，你就算携带了请求体，后端也是无法接收的。
### 文件上传

- 必须用 `POST` 方法，且前端需用 `FormData` 构造数据；
- 若上传大文件，需调整 `max-file-size` 和 `max-request-size` 配置（默认值较小，易报错）；
- 避免将文件保存到本地服务器（重启后丢失），推荐用云存储（阿里云 OSS、腾讯云 COS）。

## 附：常用方式对比表

|接收方式|适用场景|前端格式|核心注解 / 类|
|---|---|---|---|
|路径参数|RESTful 资源标识（如 /users/{id}）|URL 路径嵌入|`@PathVariable`|
|查询 / 表单参数|筛选、分页（如？name=xxx&page=1）|`application/x-www-form-urlencoded`|`@RequestParam` 或实体类|
|复杂 JSON 对象|创建 / 更新资源（如用户注册）|`application/json`|`@RequestBody`|
|文件上传|图片、文档等二进制文件|`multipart/form-data`|`MultipartFile`|

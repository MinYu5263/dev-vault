
## 核心概念
**浅拷贝（Shallow Copy）** 是指复制对象时，只复制对象本身和其中的基本数据类型，而对象内部的引用类型字段仍然指向原来的对象，也就是说，新旧对象共享这些引用类型的成员变量。

**深拷贝（Deep Copy）** 则是完全复制整个对象，包括所有的引用类型字段，这样修改其中一个对象的引用字段不会影响到另一个对象。

## 区别

关键区别在于是否创建了新对象，如果没有创建新对象，只是复制引用，就是浅拷贝，如果创建了新对象，并进行显示赋值就是深拷贝。

说明：在Java代码中，`=`只能用来进行赋值，而引用类型的值，就是其地址值，而不是对象中的值。

## 举例

### 例1：对象引用传递

```java
Class student {
String name；
int age;
//构造函数
//getter and setter
}

var zhangsan = new Student("张三"，20);
var copyValue = zhangsan;

zhangsan.setAge(21);
```

问：此时`copyValue.getAge`是多少？

答：此时`copyValue.getAge`的值是21。

解释：因为在 Java 中，对象变量存储的是对象的引用（内存地址），而非对象本身。当执行`var copyValue = zhangsan;`时，实际上是复制了引用，而非创建了新对象。
因此：
1. `zhangsan`和`copyValue`指向同一个对象实例。
2. 调用`zhangsan.setAge(21)`会直接修改该实例的`age`字段。
3. 由于`copyValue`指向同一实例，其`getAge()`方法返回的是修改后的值（21）。

### 例2：字符串不可变性

```java
String val1 = "Hello Word";
String val2 = val1;
var1 = "Hello";
```

问：此时`val2`的值是多少？

答：仍然是`"Hello Word"`。

解释：
当你执行 `String val2 = val1;`这一步就是浅拷贝，是把`val1`的引用复制给了`val2`，也就是`val1`和`val2`这两个引用都指向了同一个`String`对象。既然两个变量的引用都指向了同一个`String`对象，那为什么修改`val1`的值不会影响`val2`呢？这时因为在Java中，`String`对象具有不可变的特性，一旦`String`对象被创建，就没办法再对其进行修改。当你看似在修改`String`时，实际上 Java 会生成一个新的`String`对象，所以，`val1 = "Hello";`这一步，其实是新建了一个`"Hello"`对象，`val1`复制了这个对象的引用。

总结：虽然进行了浅拷贝，但是由于`String`对象不可变，使得任何对`String`的修改操作都会生成新的对象，所以在实际使用中，其效果和深拷贝是一样的。

## String如何实现不可变的特性？

1. 使用 `final`关键字，保证其不可变的特性
```Java
public final class String { ... }
```

2. ​​私有final字符数组，private限制外部直接访问数组，final确保数组引用不可变
```java
private final char value[]; // Java 8及以前
private final byte[] value; // Java 9及以后（优化存储）
```

`EnumMap` 是 Java 中专门为**枚举类型（Enum）作为键**设计的高效 Map 实现类（位于 `java.util` 包），自 Java 5 开始引入。它的核心特点是**用枚举常量作为键**，并通过底层数组存储值，具有极高的性能和内存效率。
### ​**关键特性**：
1. ​**专为枚举优化**
    - 键必须是同一枚举类型的实例（编译时类型安全）
    - 内部用数组存储值，索引直接对应枚举常量的声明顺序（`ordinal()` 值）
2. ​**高效性**
    - 时间复杂度：`O(1)` 的查找、插入、删除（远超 `HashMap`）
    - 内存紧凑：没有哈希冲突，空间利用率高
3. ​**键的有序性**
    - 遍历顺序与枚举常量声明顺序一致（自然顺序）
4. ​**不允许 `null` 键**
    - 但允许 `null` 值（除非显式限制）
